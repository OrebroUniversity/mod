# Warehouse (simulated)

Copied from bench-mr (https://github.com/ksatyaki/bench-mr, MIT) `maps/`: `pedsim_warehouse.yaml` / `.pgm`
(occupancy map of a simulated warehouse, 0.1 m per pixel, origin (-10, -10)) and the CLiFF-map, GMMT-map and
intensity map learned from simulated pedestrian trajectories (`pedsim_warehouse_cliff.xml`,
`pedsim_warehouse_gmmt.xml`, `pedsim_warehouse_intensity1m.xml`). bench-mr ships no start/goal pairs for it.
